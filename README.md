# Personal Portfolio Website

Welcome to the repository for my personal portfolio website!

This repository contains the source code for my portfolio, where I showcase my software development projects, technical skills, and professional experience.

Check out the live website here: **[www.tughan.de](https://www.tughan.de)**

Tech Stack & Development Journey
- **HTML5 & CSS3**
- **JavaScript**
- **Hosted on GitHub Pages**

This project started 5 years ago using a base template from [MacodeID](https://macodeid.com/). Since then, I have heavily modified, rewritten, and expanded the codebase to the point where it is now a completely custom experience.

Maintaining this project over the years has allowed me to practice reading existing code, refactoring structure, and implementing my own design systems for new, changing requirements.

## Key Features and Customizations include:
- Built custom stylesheets from scratch to handle new elements, layouts, and personalized design features.
- Completely rearranged and added new DOM elements and HTML pages to fit my specific portfolio needs.
- Ensured all custom elements and layout shifts look great on mobile, tablet, and desktop.

## A major focus of my custom overhaul was ensuring absolute privacy for my visitors and strict adherence to GDPR.
- Removed reliance on external Google Fonts to prevent third-party tracking. All fonts are now hosted locally.
- Swapped standard media embeds for privacy-enhanced alternatives (using YouTube's no-cookie domain) to ensure no tracking cookies are loaded without consent.
- Implemented legally compliant, dedicated *Impressum* and *Datenschutzhinweise* / *Privacy Policy* pages.
